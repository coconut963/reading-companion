# 共读

一个本地运行的 AI 共读批注系统。

左侧阅读章节原文，右侧让角色以自己的身份写批注。支持 EPUB 导入、角色设定、用户面具、世界观提示词、OpenAI 兼容 API、批注讨论、章末评论、主题与字体自定义。

## 功能

- 导入 EPUB 书籍
- 按章节阅读
- 支持章节分片，控制上下文长度
- 自定义角色设定
- 自定义用户面具
- 世界观提示词注入
- OpenAI 兼容 API 接入
- 角色批注
- 批注下讨论
- 章末评论区
- 章节摘要
- 主题、字体、字号、颜色设置
- 本地数据存储
- 导入导出备份

## 数据存储

所有数据默认保存在用户本机 IndexedDB 中。

包括：

- 导入的书籍
- 阅读进度
- 角色设定
- API 设置
- 批注
- 评论
- 摘要
- 字体
- 主题设置

本项目不会上传用户数据。

## API Key

本项目不会内置任何 API Key。  
用户需要在应用内自行配置 OpenAI 兼容接口。

常见兼容接口包括：

- OpenAI
- OpenRouter
- DeepSeek
- Moonshot
- 通义千问兼容接口
- 本地 Ollama/OpenAI-compatible 服务
